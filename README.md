# StoneLab

建筑石材研究数据库 · v0.3

一个在本地浏览器里运行的石材检索工具。输入名称即可查看该石材的岩石学分类、矿物组成、孔隙率与力学性能，并查看标本与薄片示意图、生成对应的理论 XRD 衍射谱。纯 Python 实现，无需服务器，无需联网。

---

## 快速开始

```bash
cd ~/Desktop/StoneLab
.venv/bin/python -m streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。按 `Ctrl + C` 停止。

### 首次在其他机器上运行

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

## 数据说明

### 收录范围

14 块常见建筑石材，覆盖三大岩类：

| 大类 | 数量 | 示例 |
| --- | --- | --- |
| 岩浆岩 | 6 | 山东白麻（花岗岩）、芝麻黑 G654（辉长岩）、福建玄武岩 |
| 变质岩 | 4 | 汉白玉（大理岩）、卡拉拉白、江西板岩 |
| 沉积岩 | 4 | 米黄大理石（石灰岩）、四川红砂岩、印度砂岩 |

### 字段定义

**孔隙率 `porosity_pct`**：开口孔隙体积占总体积的百分比。数值越高，吸水、冻融破坏与泛碱的风险越大。花岗岩通常低于 1%，砂岩可达 6% 以上。

**吸水率 `water_absorption_pct`**：饱水状态下吸入水的质量占比。与孔隙率正相关，是判断耐候性的快速指标。

**体积密度 `bulk_density_gcm3`**：含孔隙的干态密度。石英质石材普遍在 2.6–2.7，玄武岩因含铁镁矿物可达 2.9 以上。

**抗压强度 `compressive_strength_mpa`**：单轴抗压。花岗岩多在 150 MPa 以上，石灰岩与砂岩明显偏低。

**冻融质量损失 `freeze_thaw_loss_pct`**：冻融循环后的质量损失率。这是大理石类石材的短板——方解石解理发育，吸水后冻胀易剥落。

### 重要免责声明

**所有物理性能数值均为文献参考值，不是本项目实测数据。** 同一矿区的不同批次可以存在显著差异，且本项目未标注测试所依据的标准（如 GB/T 9966 或 ASTM C97）。这些数据适合用于教学、初步比选与趋势判断，**不可用于工程验收或结构计算**。

矿物含量为偏光显微镜下的体积分数估算，点计数法的典型误差在 ±3% 量级。

### 如何新增一条记录

1. 在 `data/stones.csv` 末尾追加一行，`stone_id` 顺延（如 `SL-0015`），17 个字段不可缺
2. 在 `data/minerals.csv` 追加该样品的矿物记录，`stone_id` 保持一致，`content_pct` 合计应为 100
3. 重启应用即可看到。若含量合计偏离 100，界面会在「矿物组成」处显示实际合计值

字段中含逗号时必须用双引号包裹，例如 `"K(Mg,Fe)3AlSi3O10(OH)2"`。

## 标本照与显微图

详情页的「图像」标签展示两张图：手标本（板材）外观与薄片显微结构。

### 这些图是什么

**全部 28 张图都是程序生成的示意图，不是实物照片，也不是显微摄影。**

这一点必须讲清楚。项目启动时没有条件为每块石材拍摄标本照和制作薄片，而用网上的图片冒充特定商品名石材（比如把某张通用的花岗岩照片标成「山东白麻」）属于数据造假；用 AI 生成看起来像显微照片的图放进研究数据库风险更大——标签一旦丢失，就再也分不清真假。

因此采取的做法是：由 `tools/generate_schematics.py` 按每块石材**真实的矿物组成与岩石类型**渲染示意图，并做三重标记：

1. 图像右下角烙印「示意图 · 非实物照片 / 非显微摄影」水印，脱离数据库也不会被误认
2. `data/images.csv` 的 `is_measured` 字段一律记为「否」
3. 界面顶部显示黄色警告，撤除条件是索引字段改为「是」，而不是文件名变化

### 渲染依据

| 特征 | 依据 |
| --- | --- |
| 底色 | `stones.csv` 的 `color` 字段，深色石材按亮度加权增强混合比例 |
| 矿物斑块大小 | `rock_type`：玄武岩隐晶质（6 px）、花岗岩中粗粒（30 px）、大理岩等粒（34 px） |
| 矿物配色与占比 | `minerals.csv` 的含量，按比例随机抽样 |
| 显微干涉色 | 正交偏光下各矿物的典型干涉色，斜长石额外绘制聚片双晶条纹 |
| 比例尺 | `rock_type` 对应的典型视域宽度，玄武岩 2 mm、花岗岩 5 mm |

所以花岗岩的薄片会呈现粗粒镶嵌结构、石英与长石为主并散布黑云母；大理岩是等粒方解石镶嵌；玄武岩则是细密到难以分辨单颗粒的基质。这些**结构关系是真实的**，只是图像本身是渲染出来的。

### 替换为真实照片

1. 把实物照片命名为 `<stone_id>_hand.png`，显微照片命名为 `<stone_id>_micro.png`，覆盖 `data/images/` 下的同名文件
2. 在 `data/images.csv` 中把该行 `is_measured` 改为「是」，`source` 填实际来源，`license` 填授权方式
3. 显微照片建议注明 `polarization`（单偏光 / 正交偏光）与实际 `field_of_view_mm`

代码无需改动——界面是否显示警告由索引字段决定。

### 重新生成示意图

```bash
.venv/bin/python tools/generate_schematics.py
```

该脚本会同时重写 28 张 PNG 和 `data/images.csv`，保证索引与文件不脱节。生成使用固定随机种子（由 `stone_id` 派生），因此结果可复现。

## XRD 衍射谱

详情页的「XRD 衍射」标签展示的是**理论计算谱**，不是实测谱。这一点必须先讲清楚，否则界面上的曲线很容易被误当成测试结果。

### 计算方式

1. 从 `data/xrd_peaks.csv` 读取每种矿物的参考峰位（2θ）、相对强度与晶面指数
2. 按该矿物在样品中的含量百分比给峰高加权
3. 每个峰用高斯函数展宽，半高宽 FWHM 可调
4. 全部叠加后归一到最高峰 = 100

以汉白玉为例：方解石含量 97%，其最强峰 (104) 位于 29.41°，因此合成谱的最强峰也在 29.41°，d = 3.035 Å。换成四川红砂岩，石英含量 74%，最强峰移到 26.64° (101)，d = 3.343 Å。这个变化与矿物学预期一致。

### 界面功能

| 功能 | 说明 |
| --- | --- |
| 2θ 扫描范围 | 5–70° 可调，缩小范围可放大局部峰群 |
| 半高宽 FWHM | 0.05–0.60° 可调，峰越宽代表晶粒越细或结晶度越低 |
| 峰位标注 | 前 5 个主峰以虚线标出并注明晶面与矿物 |
| 主要衍射峰归属表 | 列出 2θ、d 值、晶面指数、归属矿物、参考强度、PDF 卡片号 |
| 按矿物分解 | 每种矿物单独归一化显示，便于比较峰位重叠 |
| 物相覆盖 | 标出哪些组分有参考峰位、哪些只贡献弥散背景 |

### 已知局限

- 峰位来自参考 PDF 卡片整理，**不同卡片、不同矿物端元成分会导致峰位偏移**。斜长石的峰位随 An 值（钙长石占比）显著变化，本表用的是钠长石端元
- 未考虑择优取向。云母类矿物（黑云母、白云母、绿泥石）的 (00l) 面极易定向排列，实测谱中这些峰会异常增强，理论谱无法反映
- 未模拟仪器展宽、背景噪声与吸收效应
- 「黏土矿物」「岩屑」「玻璃质」「副矿物」无明锐峰，仅按宽包背景处理

### 接入实测数据

1. 将原始谱图存入 `data/xrd/<stone_id>.xy`（两列：2θ 与强度）
2. 在 `stones.csv` 的 `xrd_status` 字段标记为「已测」
3. 把 `app.py` 中 `render_xrd()` 的数据来源从 `synthesize_pattern()` 换为读取实测文件

峰位归属表、物相覆盖、按矿物分解这些逻辑都可直接复用，不需要重写。
